Dudas frecuentes

Preguntas frecuentes

Respuestas rápidas sobre la vinculación, la sesión y el panel.

¿Es seguro vincular mi número?

Sí. Se usa el protocolo oficial WhatsApp Multi-Device. La sesión se guarda cifrada en la base de datos y el bot solo responde a los comandos con el prefijo configurado.

¿Necesito un servidor propio?

No. Todo corre en la infraestructura del proyecto y se administra desde este panel. Solo vinculas el número y usas los comandos.

¿Cómo vinculo el bot?

Desde Conexión puedes escanear el QR o pedir un código de 8 dígitos. El código vive unos 60 segundos y el panel lo retira al expirar.

¿Puedo personalizar el menú?

Sí. En la sección Comandos puedes activar, ocultar, renombrar con alias y cambiar el texto que decora cada comando, con vista previa en vivo.

¿Qué pasa si el bot se desconecta?

El sistema detecta la caída y reconecta automáticamente. Puedes revisar el estado del servidor en la sección Monitor del panel.

¿El panel pide contraseña?

No: el panel es público y no autentica visitantes. Cualquiera con el enlace puede editar el menú, ver la actividad y usar los controles de WhatsApp. No compartas la URL si no quieres conceder ese acceso.
