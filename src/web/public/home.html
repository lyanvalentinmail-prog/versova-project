Preguntas rápidas

            

              
¿Necesito iniciar sesión?
Sí. El panel y la tienda requieren cuenta (Google o email). Así tus tokens y sub-bots quedan ligados solo a ti.

              
¿Por qué al actualizar la página no se envía un código solo?
El emparejamiento es manual: pulsa «Activar» en el bot y elige QR o código de 8 dígitos cuando lo necesites. Así no se envían códigos sin querer al recargar la página en Render.

              
¿Cuánto dura el código de vinculación?
Unos 60 segundos. El panel lo retira al expirar para que no ingreses un código que WhatsApp rechazaría.

              
¿Dónde configuro el nombre, prefijo y banner de mi bot?
Todo está dentro del editor de cada sub-bot: pulsa «Editar» en la tarjeta del bot y verás la sección Identidad con nombre visible, prefijo y texto del banner.

              
¿Puedo recuperar un token usado?
No. Cada token se canjea una sola vez al crear un sub-bot. Si eliminas el sub-bot, el token queda consumido.
